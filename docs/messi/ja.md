# メッシのデスクトップペット — 日本語ガイド

[中文](zh-CN.md) · [English](en.md) · [Español](es.md) · [日本語](ja.md) · [한국어](ko.md)

アルゼンチン代表の背番号10のユニフォームを着た、ぬいぐるみ風のデスクトップペットです。両バージョンに、大きな手を耳に添える真剣なポーズと、大きな封筒を掲げるポーズを収録。どちらも目を開けたままで、まばたきしません。ユーザー提供のぬいぐるみ画像をもとに制作しており、公式提携を示すものではありません。

## 単独ループ版の使い方

1. 単独版のZIPをすべて展開し、`Messi-Offline.exe` をダブルクリックします。
2. 6秒ごとに、待機 → 右へドリブル → 耳に手を添える → 金のトロフィーにキス → 封筒を掲げる → 話すしぐさ → 左へドリブル → 困惑した表情、の順で繰り返します。
3. 左ドラッグで位置を変更。クリックまたは右クリックでメニューを開きます。ドリブル中はデスクトップ上を移動し、マウスを重ねると移動を一時停止します。
4. 「选择并保持动作」は**動作を選んで固定**、「自动切换动作」は**自動切り替え**、「下一个动作」は**次の動作**です。
5. Esc、マウスを重ねたときの×、または「退出玩偶」（終了）で閉じます。再度EXEを開いても、単独版が重複起動することはありません。

**単独版の封筒・トロフィー・吹き出しは、あらかじめ決められたアニメーションです。実際のメール、利用枠、作業状態を示しません。** CodexやGmailに接続せず、定期タスクや自動起動設定も追加しません。実行環境と画像はEXEに内蔵され、ソースファイルは不要です。

## Codex連動版の使い方

1. 連動版ZIPを展開し、`quota-pet` フォルダーをCodexに渡して依頼します。

   > このフォルダーのSKILL.mdに従ってassets/messi/skin.jsonを起動し、実際の利用枠とローカル作業状態に接続してください。ぬいぐるみのアイコン付きデスクトップショートカットも作成してください。Gmailは無効のままにしてください。

2. または `quota-pet` 内で、インストール済みのPythonを使って実行します。

```powershell
python -m pip install Pillow
python scripts/quota_pet.py --skin assets/messi/skin.json --background
python scripts/create_shortcut.py --skin assets/messi/skin.json
```

3. マウスを重ねると状態カードが表示されます。メニューから動作を試せます。「刷新真实额度」（実際の利用枠を更新）を選ぶと利用枠のプレビューを終了します。Windowsのショートカットにはぬいぐるみのアイコンを使います。

| 実際の状態 | 動作 |
| --- | --- |
| 静止中、残り100% | 金のトロフィーにキス |
| 静止中、残り80%以上100%未満 | すっと直立し、大きな手を耳に添え、真剣な表情を維持。まばたきなし |
| 残り0% | 困惑・口をとがらせる・顔を向ける。移動を止め、¿Qué mirás, bobo? を表示 |
| 作業中、または待機中の散歩 | 左右へドリブル |
| 返信や承認待ち | 話すしぐさと ¿Qué mirás, bobo? の吹き出し |
| 別途許可したGmail確認で新着を検出 | 目を開けた真剣な表情で大きな封筒を掲げる |

リアルタイム表示では返信待ち・エラーがメールより優先され、メールが利用枠の動作より優先されます。作業中や移動中はドリブルします。利用枠プレビューでは選んだポーズが優先されますが、実際の作業状態は書き換えません。不明な利用枠を0%として扱いません。既定では5分ごとに確認し、複数の期間がある場合は残り割合が最も低いものを表示します。追加クレジットは別扱いです。

Gmailは**既定で無効**です。プラグインの接続だけでは継続的な確認に同意したことにはなりません。明示的な許可後、Codexの定期タスクで確認し、Codexの利用枠を消費します。即時プッシュではありません。必要なメールのメタデータのみを扱い、ローカル通知の確認でメールを既読にはしません。ペットを閉じても別途作成した確認タスクは止まらないため、そのタスクも一時停止してください。設定は同梱の `references/gmail.md` にあります。

通常の描画、利用枠の読み取り、作業状態の確認はモデルを呼び出さず、追加のAPIキーも不要です。作業状態はローカルの互換インターフェースを利用し、Codexの更新後に調整が必要になる場合があります。最初の作業スナップショットには会話内容が含まれることがありますが、メモリ内で状態項目だけに絞り、本文と元のスナップショットは保存しません。

プレビューは実際のアニメーションフレームから書き出したものです。アカウントのリアルタイム情報を撮影した画像ではありません。「¿Qué mirás, bobo?」は、おおよそ「何見てるんだ、ばか」というセリフで、文字のみ・音声なしです。

- 動作を見たい場合：連動版は「动作试玩」（動作プレビュー）、単独版は「选择并保持动作」を選びます。
- 利用枠を取得できない場合：Codexのログイン状態を確認。失敗時は不明として表示されます。
- 削除する場合：終了してファイルとショートカットを削除。Gmailを有効にした場合は先に定期タスクを停止します。
- Codex内蔵ペットのメニューからではなく、独立したデスクトップウィンドウとして起動します。両版は共存できます。
