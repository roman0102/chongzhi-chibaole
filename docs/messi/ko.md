# 메시 데스크톱 펫 — 한국어 사용 안내

[中文](zh-CN.md) · [English](en.md) · [Español](es.md) · [日本語](ja.md) · [한국어](ko.md)

아르헨티나 10번 유니폼을 입은 봉제인형 데스크톱 펫입니다. 두 버전 모두 큰 손을 귀에 대는 진지한 자세와 커진 봉투를 드는 최신 동작을 포함합니다. 이 두 동작에서는 눈을 뜬 채 깜빡이지 않습니다. 사용자가 제공한 인형 사진을 바탕으로 제작했으며, 공식 제휴를 뜻하지 않습니다.

## 버전 선택

| 버전 | 다운로드 | 실행 환경 |
| --- | --- | --- |
| Codex 연동판 | [Skill ZIP 다운로드](https://github.com/roman0102/chongzhi-chibaole/raw/refs/heads/main/downloads/messi-codex-skill-windows-v1.0.0.zip) | Windows, 로그인 후 실행 중인 Codex, Python 3.10 이상, Tk, Pillow |
| 독립 반복 재생판 | [오프라인 EXE ZIP 다운로드](https://github.com/roman0102/chongzhi-chibaole/raw/refs/heads/main/downloads/messi-offline-windows-v1.0.0.zip) | 64비트 Windows. Codex, Python 설치, 계정, 인터넷 연결 불필요 |

현재 Windows 11 컴퓨터에서 확인했습니다. macOS, Linux, 모바일 패키지는 제공하지 않습니다. 안내 문서만 번역되어 있으며, 프로그램 메뉴는 현재 중국어입니다.

## 독립판: 압축을 풀고 실행하기

1. 독립판 ZIP을 다운로드해 전부 압축 해제한 뒤 `Messi-Offline.exe`를 더블클릭합니다.
2. 6초마다 대기 → 오른쪽 드리블 → 귀에 손 대기 → 금빛 트로피에 입맞춤 → 봉투 들기 → 말하는 동작 → 왼쪽 드리블 → 어리둥절한 표정 순으로 반복합니다.
3. 왼쪽 버튼으로 끌어 위치를 옮깁니다. 클릭 또는 오른쪽 클릭으로 메뉴를 엽니다. 드리블할 때 바탕 화면을 이동하며, 마우스를 올리면 이동을 멈춥니다.
4. “选择并保持动作”는 **동작 선택 후 유지**, “自动切换动作”는 **자동 동작 전환**, “下一个动作”는 **다음 동작**입니다.
5. Esc, 마우스를 올렸을 때 나타나는 ×, 또는 “退出玩偶”(종료)로 닫습니다. EXE를 다시 실행해도 독립판이 중복으로 켜지지 않습니다.

**독립판의 봉투, 트로피, 말풍선은 정해진 애니메이션일 뿐 실제 메일·사용 한도·작업 상태를 나타내지 않습니다.** Codex나 Gmail에 연결하지 않으며 예약 작업이나 시작 프로그램도 추가하지 않습니다. 실행 환경과 이미지가 EXE에 포함되어 있어 소스 파일 없이 사용할 수 있습니다.

## Codex 연동판 사용하기

1. 연동판 ZIP을 압축 해제합니다. `quota-pet` 폴더를 Codex에 전달하고 다음과 같이 요청합니다.

   > 이 폴더의 SKILL.md에 따라 assets/messi/skin.json을 실행하고 실제 사용 한도와 로컬 작업 상태를 연결해 주세요. 인형 아이콘이 있는 바탕 화면 바로가기도 만들어 주세요. Gmail은 비활성화 상태로 두세요.

2. 또는 `quota-pet` 폴더에서 설치된 Python으로 실행합니다.

```powershell
python -m pip install Pillow
python scripts/quota_pet.py --skin assets/messi/skin.json --background
python scripts/create_shortcut.py --skin assets/messi/skin.json
```

3. 마우스를 올리면 상태 카드가 나타납니다. 메뉴에서 동작을 미리 볼 수 있습니다. “刷新真实额度”(실제 사용 한도 새로고침)를 선택하면 한도 미리보기가 끝납니다. Windows 바로가기에는 인형 아이콘을 사용합니다.

| 실제 상태 | 동작 |
| --- | --- |
| 정지 상태, 100% 남음 | 금빛 트로피에 입맞춤 |
| 정지 상태, 80% 이상 100% 미만 | 갑자기 똑바로 서서 큰 손을 귀에 대고 진지한 표정 유지. 눈 깜빡임 없음 |
| 0% 남음 | 눈을 크게 뜨고 입을 삐죽거리며 고개 돌리기. 이동을 멈추고 ¿Qué mirás, bobo? 표시 |
| 작업 중 또는 대기 중 돌아다닐 때 | 좌우 드리블 |
| 답변이나 승인 대기 | 말하는 동작과 ¿Qué mirás, bobo? 말풍선 |
| 별도 승인한 Gmail 확인에서 새 메일 감지 | 눈을 뜬 진지한 표정으로 큰 봉투 들기 |

실시간 모드에서는 대기·오류 상태가 메일보다, 메일이 한도 동작보다 우선합니다. 작업이나 이동 중에는 드리블합니다. 한도 미리보기는 선택한 자세를 우선 표시하지만 실제 작업 기록을 바꾸지 않습니다. 알 수 없는 한도를 0%로 취급하지 않습니다. 기본 확인 간격은 5분이며, 여러 기간 중 남은 비율이 가장 낮은 항목을 표시합니다. 추가 크레딧은 별도로 처리합니다.

Gmail은 **기본적으로 꺼져 있습니다**. 플러그인 연결만으로 지속적인 확인을 허용한 것은 아닙니다. 명시적으로 허용한 뒤 Codex 예약 작업으로 주기적으로 확인하며 Codex 사용 한도를 소비합니다. 즉시 푸시 알림이 아닙니다. 필요한 메일 메타데이터만 사용하고, 로컬 알림 확인으로 메일을 읽음 처리하지 않습니다. 펫을 닫아도 별도로 만든 확인 작업은 멈추지 않으므로 해당 작업도 일시 중지해야 합니다. 설정은 패키지의 `references/gmail.md`를 참고하세요.

일반적인 화면 표시, 한도 읽기, 작업 상태 확인은 모델을 호출하지 않고 추가 API 키도 필요하지 않습니다. 작업 상태는 로컬 호환 인터페이스를 사용하므로 Codex 업데이트 후 수정이 필요할 수 있습니다. 초기 작업 스냅샷에 대화 내용이 들어올 수 있지만, 메모리에서 상태 필드만 남기고 본문을 버리며 원본 스냅샷은 저장하지 않습니다.

## 동작 미리보기와 도움말

미리보기는 실제 애니메이션 프레임에서 내보낸 것으로, 실시간 계정 상태의 스크린샷이 아닙니다. “¿Qué mirás, bobo?”는 대략 “뭘 봐, 바보야?”라는 뜻이며 글자만 표시하고 음성은 재생하지 않습니다.

- 특정 동작 보기: 연동판은 “动作试玩”(동작 미리보기), 독립판은 “选择并保持动作”를 선택합니다.
- 한도를 읽지 못할 때: Codex 로그인 상태를 확인하세요. 실패하면 알 수 없는 상태로 표시되어야 합니다.
- 삭제하기: 펫을 종료한 뒤 파일과 바로가기를 지웁니다. Gmail을 켰다면 예약 작업부터 중지합니다.
- Codex 내장 펫 메뉴가 아닌 별도의 데스크톱 창으로 실행됩니다. 두 버전을 함께 둘 수 있습니다.

코드나 캐릭터 이미지의 제한 없는 상업적 이용을 허용하는 라이선스는 선언되지 않았습니다.
