# 重置吃饱了

额度决定胖瘦，真实任务状态决定动作。随附 Python/Tk 实现，以及清野凛的额度形态、走路和表情动画。默认小猪只用标准库；图片皮肤另需 Pillow。运行时不调用模型生成内容、不需要 API key。

## 开始玩

1. 以本文件所在目录定位 `scripts/`，不要假定用户的安装路径。确认是本地桌面环境，找到含 `tkinter` 的 Python 3.10+。Codex 提供运行时定位工具时可用它寻找自带 Python；避免误用 Windows Store 的 Python 别名。需要安装依赖时说明实际缺项。
2. 默认角色叫“饭桶”，用户没有指定形象时直接用它；名字和颜色用启动参数调整。先执行 `python scripts/codex_quota.py --json`，只读检查真实额度连接。用户只想试玩时直接用 `--demo 100`，不要求登录。
3. 实际额度查询成功后运行 `python scripts/quota_pet.py --background`。使用解析到的 Python 绝对路径；含空格路径按当前 shell 正确引用。默认只显示角色，鼠标悬停才显示额度卡和 ×，移开后隐藏。点击打开菜单，可切换模拟造型、试玩表情、暂停“自由溜达”、刷新或退出；支持拖动和 Esc。不要重复启动已运行的同一只宠物。
4. 完成时分别报告额度和工作状态的连接结果。通过实际窗口或 `--ready-file` 标记确认运行：pid 应与本次启动一致，visible 为 true；额度连接需 remaining_percent 有值且 error 为空；工作状态连接需 work_connected 为 true 且 work_state 不是 unknown。失败时保留未知，不能用试玩动作冒充任务状态。工作状态接入与排查见 [工作状态](references/work-status.md)。

## 制作与分享

用户想换角色时，在其项目中复制素材并制作实验版本，保留额度模块。代码角色可修改 `pet_art.py` 的 `draw_pet`。图片角色用可用的图像生成工具保留其身份，生成透明等格精灵图；通过 `--skin` 接入，无需重写额度连接器。原生宠物和独立额度宠物是两个运行对象，不把实验版启动说成修改了原生宠物。

### 清野凛与其他图片角色

`assets/seinorin/skin.json` 是可直接运行的示例：`python scripts/quota_pet.py --name 清野凛 --skin assets/seinorin/skin.json --background`。路径相对于启动目录；实际调用时解析为绝对路径。图片模式先确认当前 Python 可导入 `PIL`；缺少时用该 Python 安装 Pillow。默认小猪不需要此依赖。

图片模式支持静态六态和按额度切换的动作图。制作动画时读取 [皮肤格式](references/skins.md)，以 `assets/seinorin/skin.json` 为可运行示例。原生素材只复制到项目内使用；清野凛普通体型沿用原素材的待机、左右走、招手、开心跳跃、委屈动作，其他体型用内置 imagegen 补帧。提示词随素材保存于 `assets/seinorin/`。

清野凛及支持相应动作的图片皮肤，工作中播放行走动作；等待人处理时停下招手；完成或出错时短暂开心或哭泣，随后待机。相同结束事件的心跳不重复触发。空闲可自由漫游，未知静止，取消随机哭笑。默认小猪支持胖瘦、工作状态点和卡片、漫游与暂停，但没有招手、开心和哭泣的工作动画。常态只显示角色和小状态点；悬停后显示详细工作状态与额度。动作试玩有短暂标识，结束后恢复真实状态，额度试玩与工作状态彼此独立。

漫游限制在当前显示器工作区。悬停、菜单或拖拽暂停移动，工作动画仍可原地播放；拖动后等待 8 秒再出发。`--no-roam` 可关闭走动，也适合固定位置验收。

胖瘦由身体轮廓和表情变化表达。至少检查满额、半饱、饥饿、零额度和未知五种状态，保证额外点数不混入百分比。用 `--demo-cycle --no-roam --quit-after 16` 检查动画、错位和文字裁切；悬停时模拟模式必须明确标识。动画还需检查每个动作的头发和脚完整、没有邻帧碎片，hover 隐藏/显示正常，漫游不会跑出屏幕。

分享时打包 `quota-pet/` 目录，保留 `SKILL.md`、`agents/`、`scripts/`、`references/` 和选用的 `assets/`。排除废弃素材、缓存、日志、真实额度快照、凭据和本机路径。用户可将目录放到其 Codex skills 目录，重新加载后用 `$quota-pet` 调用；安装到个人配置目录须属于当前请求。运行不添加开机启动、计划任务或后台模型轮询。

## 额度语义与边界

- `codex_quota.py` 通过已登录的本地 Codex app-server 读取 `account/rateLimits/read`。使用指定额度桶，默认 `codex`，有多个窗口时按剩余比例最少的一项显示，并标注该窗口。
- 剩余比例 = 100 − usedPercent。缺失字段、未登录、网络错误均为未知。到重置时间只提示等待更新，拿到新数据后才变胖。
- 额外点数是单独的备用粮，不能用余额推算周额度。额度恢复后改变体型并显示短暂星光，工作状态仍决定动作；不发起购买或消耗重置次数。
- 额度走 app-server，工作状态走桌面本地只读订阅。均不创建对话，不读取凭据或会话日志，不修改 Codex 安装包或内置宠物设置。初始工作快照在内存中缩减为状态字段，正文立即丢弃、不保存、不发送。两个连接器分开排查，另开的 app-server 不代表正在运行的桌面任务。
- 当前版本使用独立 Tk 窗口。Windows 支持透明背景；其他系统按 Tk 能力适配，透明不可用则使用普通小窗。仅对实际测试过的系统声称验证通过。

参数与故障处理查看各脚本的 `--help`。`--snapshot` 是额度快照，`--work-status-file` 是外部工作状态心跳；后者超过 30 秒自动转未知。分享包不包含真实快照、聊天 ID 或机器配置。

官方依据：[额度接口](https://learn.chatgpt.com/docs/app-server)、[原生宠物的支持范围](https://learn.chatgpt.com/docs/pets)。
