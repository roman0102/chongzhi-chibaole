# 图片皮肤

在角色的项目目录保存 JSON 与 PNG/WebP，通过 `--skin` 加载。图片文件名与 JSON 同目录；避免硬编码本机路径。运行时需要 Pillow。

## 桌面图标

为角色保存一个独立的方形头像和 Windows `.ico`，在皮肤 JSON 中添加可选字段 `"icon": "角色图标.ico"`。文件与 JSON 同目录，使用相对文件名。l2m_serinorin已经附带 `seinorin-desktop-icon.ico` 和 PNG 原图；其他角色使用自己的头像，不能沿用l2m_serinorin或 Python 图标。这个字段供快捷方式助手读取，动画播放器无需修改。

创建或换角色完成后按 [桌面快捷方式](shortcuts.md) 更新桌面入口。快捷方式图标跟随所选角色，不随额度动画实时变化。

## 六种额度形态

固定键名：`full`（80–100%）、`round`（50–80%）、`normal`（20–50%）、`hungry`（大于 0、小于 20%）、`empty`（0%）、`unknown`（未取得额度）。分界值取较高一档。

静态皮肤配置 `name`、`image`、`columns`、`rows`，及 `states` 到零基格号的映射。按从左到右、从上到下计数。每格统一镜头、身高和基线，用身体宽度与表情表现胖瘦。

## 动画皮肤

添加 `animations`，键是上述额度形态。每项配置 `image`、`columns`、`rows` 和 `clips`；某个形态可用字符串引用另一形态，例如 `"unknown": "normal"`。静态图与动画可以并存，未配置动画的形态使用静态帧。

动作名为 `idle`、`walk-right`、`walk-left`、`happy`、`cry`、`wave`。必须有 `idle`；缺少的动作回退到待机。每段用 `row`（零基行）、`frames`（从第 0 列起的有效帧数）、`ms`（每帧毫秒数）声明。左行动作图本身应朝左，绘制层不再次镜像。

生成图未严格对齐格子时，先确认相邻角色之间有透明间隔。可用每段 `boxes` 指定各帧的 `[左,上,右,下]` 像素矩形，代替 `row`；框数量就是帧数。全部框均需在图片内，并包含完整头发、脚与表情。只有各行高度不同则可用整张图的 `row_edges`。角色实体互相接触时应修正素材排布，不能用矩形硬切出残缺人物。

角色高度最高 212 像素、宽度最高 220 像素，绘制层将同一图中有效帧按统一尺度处理，底部对齐。Windows 透明色窗口会在内存中调整 alpha 边缘，源图保持不变。动画帧按当前动作已经播放的秒数选取，PhotoImage 按动作缓存。

l2m_serinorin例子：普通和未知形态使用原生大头 Q 版的动作副本，其余四档使用补全的动作图；素材与生成提示词均在 `assets/seinorin/`。这是独立桌宠的动作播放，原生宠物设置和原文件保持不变。

## 事件动作与气泡

可选 `presentation` 将事件映射到专用动画。支持额外动作名 `trophy`、`ears`、`depleted`、`mail`、`bobo`，配置引用的动作必须在六个额度状态的 clips 中均可用；状态可引用同一张图。

```json
{
  "presentation": {
    "full": "trophy",
    "high": "ears",
    "high_min": 80,
    "empty": "depleted",
    "waiting": "bobo",
    "mail": "mail",
    "hold": ["ears"],
    "bubbles": {"bobo": "¿Qué mirás, bobo?", "depleted": "¿Qué mirás, bobo?"},
    "labels": {"trophy": "亲吻金杯", "ears": "捂耳庆祝", "depleted": "没额度了", "mail": "晒邮件（动作演示）", "bobo": "等你回应（动作演示）"}
  }
}
```

`full` 仅指剩余 100%；`high` 从 high_min（默认 80）起、严格小于 100%。这两个动作替换静止待机；工作和漫游仍播放左右带球动作。0% 使用 empty 动作并停止漫游；未知额度使用普通待机，不冒充没额度。

优先级为菜单动作试玩、等待用户处理、错误状态、短暂新邮件提醒、零额度动作、工作/漫游、静止时额度动作。错误状态沿用 cry 后回到待机的规则。新邮件在等待或错误状态下延后提醒。Gmail 真实连接仍需按 Gmail 文档单独启用；菜单动作只演示姿态。

`bubbles` 是随对应动作显示的文字，动作结束立即消失，不发出语音。`labels` 提供右键动作试玩条目。带气泡的皮肤高度缩至不超过 170 像素，留出头顶空间；旧皮肤不受影响。

`hold` 列出的动作只播放一次并保持最后一帧。公仔的捂耳动作在 100 毫秒后站直，保持睁眼严肃姿势。重新选择该动作或离开再进入时重新播放。

额度试玩优先显示选定额度的造型并暂停移动，避免被真实工作或等待状态覆盖；额度卡仍记录真实工作状态，模拟数据标识保留。菜单“刷新真实额度”退出额度试玩后恢复真实状态驱动。菜单“动作试玩”可暂时覆盖额度试玩。
