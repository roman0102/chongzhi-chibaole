# Windows 桌面快捷方式

首次配置可长期使用的桌宠，以及制作或换角色的收尾步骤：让用户以后能双击桌面入口启动当前角色，并通过头像认出它。仅说明用法、排查连接或临时试玩时无需创建。

## 准备角色图标

清野凛的 `assets/seinorin/skin.json` 已声明配套 `.ico`，可直接复用。自定义角色和默认小猪都应使用符合当前形象的图标：优先使用已有头像；需要创作头像时用可用的图像工具保持角色身份，生成透明方形头像，保存到角色素材目录。不要把整张精灵图当图标。清野凛的图标仅适用于清野凛。

助手接受现成 `.ico`，也可将方形 PNG 封装为多个尺寸的 ICO；后者需要 Pillow。头像和 ICO 都保存到长期保留的 Skill 或角色项目目录，再写入快捷方式，避免引用生成缓存或临时目录。皮肤 JSON 可声明 `"icon": "角色图标.ico"`，与 JSON 同目录；无皮肤的代码角色同时显式指定名称和图标，例如 `python scripts/create_shortcut.py --name 饭桶 --icon assets/pig/pig-icon.ico`（先准备好该图标文件）。

## 创建与更新

用已经确认可运行桌宠的 Python 调用助手。下面路径相对 Skill 根目录；实际执行时解析为绝对路径并按 shell 正确引用：

```powershell
python scripts/create_shortcut.py --skin assets/seinorin/skin.json --accent '#9270d6'
```

默认名称是「角色名 · 重置吃饱了」，位置取 Windows 实际桌面目录，兼容桌面重定向。启动目标使用该 Python 的 `pythonw.exe` 和本 Skill 的 `quota_pet.py`，免去命令行窗口。创建快捷方式不会再次启动宠物。

颜色、固定位置、额度刷新设置等应与实际启动配置一致，可传 `--color`、`--accent`、`--no-roam`、`--interval`、`--bucket` 和 `--codex`。工作范围默认 `desktop`；若只跟随一个聊天，必须显式传 `--work-thread`，因为桌面双击不会继承 Codex 当前聊天的环境变量。

换角色时，使用 `--shortcut-path` 指向原有桌面快捷方式，并传入新角色的完整配置（`--name`、`--skin`、图标以及所需的颜色、工作范围等），在同一入口更新目标参数和图标；不要仅换图标却仍启动旧皮肤。新角色没有配套图标时先制作，不回退到 Python 图标。助手参数见 `--help`。

助手仅更新可确认属于本 Skill 的入口；同名无关快捷方式保留，另选名称。桌面写入若受当前环境权限限制，走正常权限流程并如实说明，不能把工作区测试文件当作用户桌面入口。它不添加开机启动，不修改 Codex 原生宠物设置。

## 验收与交付

读取助手返回的 JSON，确认 `verified` 为 true，快捷方式存在且目标、参数、图标对应当前角色。图标源文件必须存在；助手会通知 Windows 刷新。换图标时无需重复启动正在运行的宠物。当前宠物脚本不防多开，验证启动前先检查是否已有同一只。

交付时告诉用户实际桌面入口名称和位置。卸载时先退出宠物，再删除对应快捷方式及已安装的 Skill。若只移动角色素材，重新运行助手修正路径；若移动整个 Skill，旧入口不再通过当前安装的来源校验，应指定新的快捷方式路径，验证成功后再处理旧入口。
