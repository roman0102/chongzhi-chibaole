# 重置吃饱了 🐾

给 Codex 养一只会被你饿瘦的桌宠。额度满时胖成球，用着用着就瘦了，额度恢复后再长回来。

**l2m_serinorin（l2m工作室吉祥物）** 示例还能跟随本机 Codex 桌面聊天的工作状态走路、招手、开心和哭泣。平时只显示角色和一个小状态点，鼠标移上去才显示详情。

这是一个个人制作的 **Windows 实验版 Skill**，包含制作指引、运行脚本和角色素材。桌宠以独立悬浮窗运行。

## 安装和开始玩

需要 Windows、已登录且正在运行的 Codex 桌面端，以及含 Tk 的 Python 3.10+。l2m_serinorin图片皮肤另需 Pillow。可以让 Codex 检查并协助准备环境。

把本仓库链接交给 Codex，并告诉它：

```text
请从这个仓库的 skills/quota-pet 目录安装「重置吃饱了」Skill：
https://github.com/roman0102/chongzhi-chibaole
安装完成后告诉我如何启动l2m_serinorin示例，并检查运行环境。
```

安装后，在下一轮对话发送：

```text
用 $quota-pet 启动l2m_serinorin，接入真实额度和本机 Codex 工作状态，最后创建带她头像的桌面快捷方式。
```

也可以下载仓库 ZIP，将 `skills/quota-pet` 整个目录放入自己的 Codex skills 目录，默认位置是 `~/.codex/skills/quota-pet`；如果设置了 `CODEX_HOME`，使用其中的 `skills` 目录。已经装过同名 Skill 时，让 Codex 检查已有版本后再更新。

只想先看效果，可以说“用模拟额度试玩l2m_serinorin”。模拟额度不要求账号登录；工作状态连接会独立尝试读取本机桌面状态。

首次配置完成后，Skill 会在 Windows 桌面创建「l2m_serinorin · 重置吃饱了」快捷方式，图标就是她的头像。以后关闭桌宠后，双击即可再次启动。换成自己的角色时，Skill 会同步更新快捷方式的启动皮肤和图标。临时试玩不创建桌面入口。

## 上传自己的图片，做成你的桌宠

**可以用自己的图片。** l2m_serinorin（l2m工作室吉祥物）是随包提供的示例；你也可以把喜欢的人物、宠物、玩偶或原创角色图片附在 **Codex 对话**里，让 Skill 制作专属桌宠。已经开始玩了，也可以随时发新图片换角色。

安装 Skill 后，上传图片并发送：

```text
用 $quota-pet 把我上传的这张图片做成桌宠，名字叫「你想取的名字」。
尽量保留图片里角色的外观，制作随额度变胖变瘦的形态，以及走路、招手、开心和哭泣动作。
接入 Codex 的额度与工作状态，最后创建桌面快捷方式，图标也用这个角色。
```

一张清晰图片就能作为起点，单个主体、正面、身体完整的图片更容易制作。只有头像或半身照时，需要生成工具补全身体，生成结果可能需要调整。

Codex 会先根据参考图制作透明角色素材、不同胖瘦形态和动作帧，再生成皮肤配置及头像图标，接到现有桌宠程序上。上传和制作都在 Codex 对话里完成；桌面程序负责播放制作好的皮肤。你的参考图不会因此自动公开到这个 GitHub 仓库。

**制作新形象需要当前 Codex 环境可用的图像生成能力，并可能使用相应额度。** 单张静态图片本身不包含动作，不能保证一次生成就完成全部动画或与原图逐像素一致；制作完成后的日常播放不需要持续生成图片。没有图像生成能力时，可以先玩随包角色，或提供已经做好的精灵图和皮肤配置。

## 可以怎么玩

- 额度决定胖瘦。默认每 5 分钟查询一次，也能在菜单里手动刷新。
- l2m_serinorin在工作时走动，等你回复或批准时招手，完成时开心，出错时哭一下。
- 空闲时自由溜达，拖动可以换位置，悬停会暂停移动并展开信息卡。
- 点击角色打开菜单，试玩不同体型和表情，也能暂停溜达或退出。信息卡上的 × 和 Esc 同样可以退出。
- 可以让 Codex 按 Skill 指引，换成你自己的角色或制作新的图片皮肤。

没有图片皮肤时，默认小猪只依赖 Python 标准库。它有胖瘦、状态显示和漫游，但没有l2m_serinorin的整套招手、开心、哭泣动画。

## 可选：让她提醒 Gmail 新邮件

**默认关闭，下载或启动桌宠不会查邮箱。** 如果你授权启用，Skill 会复用 Codex 的 Gmail 连接，通过 Codex 定时任务检查指定账号的收件箱。建议每 5 分钟一次，**会使用 Codex 额度**；需要相应连接和调度能够运行，属于定期检查，不是即时推送。

授权后，她会这样回应：

| 情况 | l2m_serinorin的反应 |
|---|---|
| 首次连接成功 | 建立起点，旧邮件不会一下子全弹出来 |
| 检测到新邮件 | 短暂招手，出现信封和待确认数量 |
| 鼠标移到她身上 | 显示发件人和标题；长标题会截短 |
| 提醒还没确认 | 保留信封，随后继续原来的工作动作；同一封不会每轮都招手 |
| 点击菜单里的“确认邮件提醒” | 清除本地提示；Gmail 邮件的已读状态保持原样 |
| 连接失败或长时间没更新 | 明确显示异常或过期，不装作没有邮件 |

工作需要你处理或出现错误时，原来的工作动作优先；邮件仍有信封提示。额度继续决定胖瘦。默认小猪能显示信封和提示卡，但没有l2m_serinorin的招手动作。

想启用时可以对 Codex 说：

```text
给「重置吃饱了」开启 Gmail 新邮件提醒。
我同意通过 Codex 定时检查指定 Gmail 账号，每 5 分钟一次，使用 Codex 额度。

请让我选择账号，并在接通后更新桌面快捷方式。
```

也可以只试玩动作，无需 Gmail 授权：

```powershell

```

发件人和标题会经过 Codex 工具上下文，并在本机私有目录保存有限的提示与去重信息。桌宠不保存 Gmail 登录令牌，不请求全文或附件，不自动回复、删除、加标签或标为已读。关闭桌宠窗口不会停掉独立的定时检查；停用时让 Codex 暂停对应任务并关闭邮件提醒。详细配置、数据范围和关闭步骤见 [Gmail 说明](skills/quota-pet/references/gmail.md)。

## 边界和数据说明

**当前完整体验只在 Windows 上验证。** 其他系统的工作状态连接尚未实现。这个 Skill 不会改写 Codex 安装包或原有宠物设置，也不会自动充值、重置额度或添加开机启动。Gmail 定时检查仅在你单独启用后配置。

额度来自已登录 Codex 的 `account/rateLimits/read`。多个额度窗口中选择剩余比例最低的一项显示，额外点数单独显示。它不是逐 token 的实时计费表，读取失败会显示未知。桌宠绘制、额度和工作状态连接不调用模型，也不需要另外填写 API key；额度查询仍需要 Codex 账号连接。可选 Gmail 检查运行于 Codex 定时任务，会使用 Codex 额度。

工作状态使用本机 Windows 桌面的兼容接口，已核对桌面版本 `26.1021.3705.0`。该接口不是公开稳定 API，Codex 更新后可能需要适配。默认从最近 50 个未归档聊天 ID 开始发现并持续跟随可用的本机聊天，不覆盖所有远程或云端任务。

连接工作状态时，桌面会发送一次包含会话内容的初始快照。脚本在内存中解析后仅保留状态字段，丢弃正文和工具内容，不将原始快照保存、记录到日志或发送出去。长聊天初次连接可能出现较高瞬时内存占用，不能把它理解成始终低内存的小挂件。具体状态范围和测试数据见 [工作状态说明](skills/quota-pet/references/work-status.md)。

## 自己运行或改角色

在 `skills/quota-pet` 目录下运行，使用实际安装的 Python：

```powershell
python -m pip install Pillow
python scripts/codex_quota.py --json
python scripts/quota_pet.py --name l2m_serinorin --skin assets/seinorin/skin.json --background
python scripts/create_shortcut.py --skin assets/seinorin/skin.json --accent '#9270d6'
```

默认小猪可以直接运行 `python scripts/quota_pet.py --background`，无需安装 Pillow。图片皮肤格式见 [皮肤说明](skills/quota-pet/references/skins.md)，完整制作流程见 [SKILL.md](skills/quota-pet/SKILL.md)。

快捷方式助手只创建或更新桌面入口，不会再启动一只宠物。自定义角色的图标配置与已有入口更新见 [快捷方式说明](skills/quota-pet/references/shortcuts.md)。

卸载时先暂停已启用的 Gmail 定时任务，通过菜单退出桌宠，再移除对应桌面快捷方式和已安装的 `quota-pet` Skill 目录。移动安装目录后需重新创建快捷方式。
